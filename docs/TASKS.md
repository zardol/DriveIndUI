## Совместная работа

Задачи выполняются в отдельных рабочих копиях. K02 меняет только `apps/web`; K03 — только `packages/simulation`. Общие типы, зависимости и lock-файл меняет оркестратор. На первом этапе Antigravity вернул пакеты исходников: оркестратор проверил пути, код и совместимость с общим контрактом, затем применил изменения и запустил проверки. Слияние выполняется после интеграционного ревью.

Первый ПК отвечает за постановку задач, общие контракты, интеграцию, проверки и GitHub. На втором ПК Sonnet готовит интерфейс, Opus — модель и сложную расчётную логику. Codex со второго аккаунта остаётся резервом для ревью. Завершённые задания не перезапускаются без новых требований или выявленного дефекта.
