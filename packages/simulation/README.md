# Модель производства

Модель иллюстративная; параметры не являются производственными данными АЛЛЮР.

- Одна смена — 28 800 секунд, план — 70 годных автомобилей.
- Исходное состояние: один кузов в очереди сварки. Следующий поступает каждые 240 секунд, если во входном буфере есть место. При полном буфере поступление пропускается и не учитывается в принятом объёме.
- Циклы участков и вместимость буферов определяются общим пакетом `@driveindui/shared`.
- Каждый участок одновременно обрабатывает одно изделие. Готовое изделие занимает оборудование, пока в следующем буфере нет места.
- Доля брака задаётся вероятностью 3% при выходе из контроля качества. Генератор с seed 42 воспроизводит одинаковые результаты.

## Сценарии

| Сценарий | События по модельному времени |
| --- | --- |
| `normal` | Нет механических отказов; ожидание и блокировка возможны из-за разной мощности участков |
| `equipment` | С 600-й секунды цикл окраски увеличивается в 1,8 раза; с 1200-й по 2100-ю секунду установка остановлена; затем восстанавливается |
| `bottleneck` | С 600-й секунды цикл сборки увеличивается вдвое до конца смены |

Эти события заранее заданы симулятором. Оценка выпуска использует только фактический средний темп и не обращается к расписанию будущих событий. Она не является моделью предиктивного обслуживания.

## Инварианты

`поступило = годные + брак + незавершённое производство`. Незавершённое производство включает очереди и изделия на оборудовании, в том числе заблокированные после обработки.

Один шаг равен одной секунде. Переданное на следующий участок изделие начинает обрабатываться не раньше следующего шага. Разбиение интервала на несколько вызовов `advanceEngine` не меняет результат.

`downtimeSeconds` учитывает остановку оборудования: отказ, обслуживание или переналадку в расчётной ветви. Загрузка — доля времени обработки с начала смены, а не текущий бинарный признак работы. Снимок не содержит изменяемых ссылок на внутреннее состояние модели. История сохраняется раз в модельную минуту.

## Сценарное сравнение

`cloneEngine` создаёт независимую копию состояния. `compareEngine(engine, options)` продолжает три копии до конца смены и не изменяет исходный движок. `maintenanceMinutes` принимает 5/10/15/20, `reserveSetupMinutes` — 0/5/10/15. Отсчёт начинается в текущую секунду, текущий прогресс обработки сохраняется.

- Продолжение смены сохраняет расписание событий.
- Обслуживание заменяет оставшиеся события окраски остановкой на выбранное время. После неё окраска работает с номинальной скоростью.
- Резерв останавливает сборку на время подготовки, затем удваивает скорость её обработки до конца смены. Замедление сценария сохраняется: под действием узкого места удвоение возвращает номинальную скорость. Это агрегированное приближение мощности, не модель двух параллельных постов.

История до начала решения общая, дальнейшие ветви независимы. `planGap` — годный выпуск минус план; дельты выпуска и простоя считаются относительно продолжения смены. Сравнение знает будущие события учебного сценария. Оно не гарантирует положительный эффект обслуживания: в штатном режиме или к концу смены вмешательство может снизить выпуск.
